# Balatro Lucky Hand v0.1.0 — 首次公开发布 / First Public Release

## 中文

小丑牌单机游戏内控制面板，首次公开版本；基于此前开发编号 `0.8.1`，统一对外版本为 `0.1.0`。

**当前功能**

- 指定下一次补牌的真实实例，支持队列排序、删除、清空，以及经确认生成本手临时官方扑克牌。
- 一次性选择合格的 Boss、商店、补充包和支持的官方随机结果；提供基础概率控制。
- 为已有小丑牌应用闪箔、镭射、多彩或负片等官方版本。
- 官方图鉴、卡牌预览与悬停介绍、搜索筛选、下拉选择、页面记忆、简体中文 / English 和可配置面板快捷键。

**安装：** 下载 Assets 中的 `Balatro-Lucky-Hand-0.1.0-windows-x64.zip` → 完整解压 → 退出游戏 → 双击 `install.cmd` → 选择游戏目录并输入 `INSTALL` → 进入牌局按下并松开 **F8**。包内含 Lovely `0.10.0` 和 SMODS `26.829.0`，无需分别下载；游戏本体需自行合法安装。

**适用范围：** Windows 11 x64、Steam Balatro `1.0.1o-FULL`，使用包内固定前置版本。完整实机及跨电脑验收尚未完成，其他版本和第三方内容 Mod 不在已验证范围。首发检查限定两次：文件/语法/预览回归检查，以及最终 ZIP 的隔离安装检查。

待执行队列不写入存档；已获得的卡牌和应用的版本仍由战局保存。旧开发版 `0.8.0` 无法追溯对象来源，建议用新牌局验证发现保护修复。

本 Mod / 安装器为 **MIT**；Lovely 为 **MIT**；SMODS 为 **GPLv3**，完整源码与许可随包保留。附件另附 SHA-256 校验文件。

## English

First public release of the in-game single-player Balatro controller, renumbered from development build `0.8.1` to `0.1.0`.

**Features:** next-draw queues for existing instances, confirmed temporary official cards, one-shot eligible Boss/shop/booster and supported random choices, basic probability controls, owned Joker editions, a read-only catalog, previews and hover descriptions, search/filtering, dropdowns, remembered views, Chinese/English and a configurable panel key.

**Install:** download the Windows x64 ZIP from Assets → extract all files → close Balatro → run `install.cmd` → select the game folder and type `INSTALL` → enter a run and press/release **F8**. Lovely `0.10.0` and SMODS `26.829.0` are included. Supply your own legally installed game.

**Scope:** Windows 11 x64, Steam Balatro `1.0.1o-FULL` and the bundled dependencies. Complete live functional and cross-machine acceptance remain pending; other versions and third-party content Mods are unverified. Release checking is limited to two executions: package/syntax/preview checks and isolated installation checks from the final ZIP.

Pending queues are not saved; native outcomes and applied editions remain in the run. Old development `0.8.0` saves lack reliable provenance for earlier choices. Controller/installer: **MIT**; Lovely: **MIT**; SMODS: **GPLv3**, with complete source and notices included. A SHA-256 checksum accompanies the ZIP.
